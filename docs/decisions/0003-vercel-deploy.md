# 0003 웹은 Vercel 로 배포한다 — dev · 운영 · PR 미리보기

- 상태: 제안
- 날짜: 2026-11-25
- 정한 곳: PR #4

## 정한 것

- `main` 은 운영 주소, `dev` 는 dev 주소, PR 마다 미리보기 주소로 자동 배포한다. 루트는 `apps/web`.
- 미리보기는 로그인 없이 열리게 둔다(공개 레포라 감출 것이 없고, 리뷰어가 바로 본다).
- 배포 PR(`dev` → `main`) 병합이 곧 운영 배포다. 주소와 관리자는 `docs/agent-guide.md` "배포" 절.

## 왜

리뷰어가 로컬에서 띄우지 않고 PR 미리보기로 화면을 보고, 앱 웹뷰가 dev 주소를 볼 수 있게 하려고.

## 버린 안

- 배포 없이 로컬에서만 확인 — 리뷰어마다 띄워야 하고, 웹뷰를 실제 주소로 시험할 수 없다.

## 다시 열 조건

- 무료 플랜 한도에 걸리거나, 관리자 한 명에게 묶인 것이 불편해지면(팀 계정 · 이전).
- 서버 dev 주소가 생겨 미리보기와 CORS 를 맞춰야 할 때 — 환경 변수와 허용 주소를 함께 정한다.
