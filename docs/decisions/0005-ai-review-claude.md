# 0005 AI 리뷰는 CodeRabbit 대신 Claude 리뷰로

- 상태: 제안
- 날짜: 2026-11-26
- 정한 곳: PR #4

## 정한 것

CodeRabbit 시범 운영을 끝낸다. 앱이 조직에 설치돼 있어 설정 파일이 없으면 기본값(자동 리뷰·요약 켜짐)으로 돌기 때문에, `.coderabbit.yaml` 에는 자동 리뷰·요약·상태 댓글·병합 전 검사·자동 답글을 끄는 설정만 남긴다. 조직 앱 설정에서 이 레포를 빼면 그 파일도 지운다. AI 리뷰는 Claude 리뷰로 바꾸고, 설정과 쓰는 법은 리뷰 흐름을 정하는 다음 PR 에서 만든다.

## 왜

- 지금 플랜은 포함된 리뷰가 **한 시간에 1회**다(PR #4 리뷰 결과에 적힌 문구). 커밋을 더 올리거나 PR 이 여러 개 열리면 리뷰가 건너뛰어진다.
- Claude 리뷰는 레포의 `AGENTS.md` 와 코드 기준 장부를 읽고 번호(`C-xx`)로 지적하게 만들 수 있다.

## 버린 안

- CodeRabbit 유지 — 지적의 질은 좋았다(PR #4 에서 막기 훅 구멍 5개를 찾음). 한도 때문에 팀 규모에서 쓰기 어렵다.

## 다시 열 조건

Claude 리뷰의 비용이나 품질이 기대에 못 미치면 다시 비교한다.
