# 0002 전역 상태 스토어 없이 시작한다

- 상태: 확정
- 날짜: 2026-11-23
- 정한 곳: 2026-11-23 웹 파트 회의

## 정한 것

서버 값은 React Query, 화면 값은 `useState` · URL 파라미터 · Context 로 다룬다. 전역 상태 스토어 라이브러리는 들이지 않는다.

## 왜

서버 값을 스토어에 복사하면 캐시가 두 벌이 되고 서로 어긋난다. 처음부터 스토어를 두면 서버 값까지 스토어로 옮기기 쉽다.

## 버린 안

- 처음부터 전역 스토어 — 필요한 화면이 아직 없다. 필요해지면 Zustand 를 후보로 본다.

## 다시 열 조건

여러 화면이 깊게 공유하는 클라이언트 값(서버 값이 아닌 것)이 생겨 Context 로 다루기 어려워지면.
