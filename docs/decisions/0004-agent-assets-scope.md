# 0004 레포에는 어기면 팀원이 피해를 보는 에이전트 규칙만 둔다

- 상태: 제안
- 날짜: 2026-11-24
- 정한 곳: PR #4

## 정한 것

- 레포가 정하는 것: 위험 명령 막기 4개(`.env` 읽기 · 검사 건너뛰기 · lease 없는 강제 푸시 · npm·yarn·bun 설치), 코드 기준 장부 · 경로별 룰 · 린트 · CI, 커밋 · PR · 배포 · 확인 스킬.
- 각자 정하는 것: 완료 검사 절차, 화면 확인 방법, 보고 형식, 확인 창을 띄울지, 워크트리.
- 막기는 확인 창 없이 바로 거절한다.

## 왜

- 일하는 절차는 사람마다 다르고 써 보면서 바뀐다. 레포에 두면 모두에게 고정되고, 바꿀 때마다 팀 레포를 고쳐야 한다.
- 확인 창은 세션을 여러 개 돌리거나 권한을 풀고 쓰는 사람의 작업을 멈춰 세운다.

## 버린 안

- 완료 관문 · 수정 직후 린트 · 변경 크기 판정을 레포 훅으로 — 개인 방식을 모두에게 강제한다.
- 되돌리기 어려운 명령(`reset --hard` 등)에 확인 창 — 잃는 것이 자기 작업뿐이고 작업이 멈춘다.

## 다시 열 조건

같은 사고(키 노출, 남의 커밋 덮어쓰기 등)가 막기 밖에서 생기면 막기를 더한다. 기준: 어기면 팀원이 피해를 보는가.
