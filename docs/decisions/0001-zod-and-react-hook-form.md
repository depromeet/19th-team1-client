# 0001 응답·폼 검증은 Zod, 폼은 React Hook Form + Zod

- 상태: 확정
- 날짜: 2026-11-23
- 정한 곳: 2026-11-23 웹 파트 회의 · PR #3

## 정한 것

서버 응답과 폼 입력은 Zod 스키마로 검사하고, 타입은 스키마에서 꺼낸다. 폼은 React Hook Form + Zod(`zodResolver`)로 만든다.
API 클라이언트(`apps/web/src/lib/api`)는 응답 스키마를 꼭 받는다.

## 왜

- 응답을 받는 자리에서 계약을 검사해야 서버 응답이 바뀌었을 때 화면이 아니라 파싱에서 바로 드러난다.
- 응답 검증과 폼 검증을 한 도구로 맞추면 스키마와 타입을 한 가지 방식으로 읽고 쓴다.

## 버린 안

- openapi-typescript(서버 OpenAPI 문서에서 타입 생성) — 지금은 쓰지 않는다. 나중에 Zod 와 같이 쓸 수 있다.

## 다시 열 조건

서버가 OpenAPI 문서를 안정적으로 제공해 손으로 쓰는 스키마와 자주 어긋나면, 타입 생성을 함께 쓰는 것을 다시 논의한다.
