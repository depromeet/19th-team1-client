# 앱 (apps/mobile)

앱은 웹뷰를 감싸는 셸이다. 화면은 웹(`apps/web`)에서 만든다.

- 앱에 화면을 새로 만들지 않는다. 앱에 들어가는 것은 웹뷰 설정, 네이티브만 할 수 있는 기능(푸시·사진·공유 등), 그리고 웹과 주고받는 메시지다.
- 웹 ↔ 앱 메시지 형식(브리지)은 아직 정하지 않았다. 새 메시지가 필요하면 만들기 전에 사람에게 묻는다.
- 패키지는 `apps/mobile` 에서 `npx expo install <패키지>` 로만 설치한다 — SDK 와 맞는 버전을 고른다.
- `ios/` · `android/` 폴더는 생성물이다. 손으로 만들거나 고치지 않고 `app.json` 과 config plugin 으로 설정한다.
- 네이티브 코드가 있는 라이브러리를 더하면 Expo Go 로는 못 띄운다. 개발 빌드가 필요하다고 보고에 적는다.
- Expo API 는 SDK 마다 바뀐다. `package.json` 의 `expo` 메이저 버전에 맞는 문서(`https://docs.expo.dev/versions/v<메이저>.0.0/`)를 본다.
- 컴포넌트 크기·메모이제이션 기준은 웹과 같다 (C-15 · C-20).
