# TypeScript

`any` · `!` · 이중 단언(`as unknown as`) · 객체 모양 `type`(→ `interface`, C-39) · `@ts-ignore` 는 ESLint 가 막는다. 여기는 기계가 판정하지 못하는 것만 둔다.

- **옵셔널(`?`)은 최후 수단이다 (C-04).** 기본값 → 의미 있는 빈 값 → 판별 유니온 순서로 먼저 시도한다.
  타입 에러를 피하려고 `?` 를 붙이지 않는다. 값이 없을 수 있으면 경계(응답 파싱·props 입구)에서 한 번 처리한다.
- **단언(`as`)은 이유가 있을 때만 (C-05).** 타입 가드나 스키마 파싱으로 좁힐 수 없을 때만 쓰고, 왜 안전한지 주석을 단다.
- **모르는 값은 `unknown` 으로 받고 좁힌다.** 범용 함수는 제네릭으로. 외부 입력(응답·URL·저장소)은 Zod 로 검사한 뒤 쓴다.
- **3분기 이상은 `Record<Union, …>` 매핑으로.** 유니온에 값이 늘면 타입 오류로 빠진 곳을 찾게 한다.
- **`export *` 를 쓰지 않는다 (C-10).** 다시 내보낼 때는 이름을 골라서.
- **ESLint 규칙을 끌 때는 같은 줄에 이유 (C-40).** `// eslint-disable-next-line <규칙> -- <왜 안전한가>`. 파일 전체 끄기는 쓰지 않는다.
