# features

기능(도메인)별 코드를 모은다. 한 기능에서만 쓰는 것은 그 기능 폴더에 두고, 두 기능 이상이 실제로 같이 쓰게 되면 `src/lib`(로직)·`src/components`(화면 부품)로 올린다.

```
features/<도메인>/
├─ api/          서버 응답 스키마(엔드포인트 하나에 파일 하나, C-51)
├─ hooks/        화면 쪽 훅(쿼리·뮤테이션 훅은 아래 참고)
├─ forms/        폼 입력 스키마
└─ components/   화면
```

- 쿼리·뮤테이션 훅을 어디에 어떤 이름으로 둘지는 아직 정하지 않았다 — 장부 C-26 · 보류 "쿼리 훅 모양". 첫 API 연동 PR 에서 정한다.
- 파일·폴더 이름은 장부 C-38, 코드 기준 전체는 `docs/code-standards.md`.
