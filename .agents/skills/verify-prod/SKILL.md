# 운영 확인

운영 주소: https://19th-team1-client.vercel.app

**읽기만 한다.** 가입·저장·삭제·결제처럼 운영 데이터를 만들거나 바꾸는 동작은 하지 않는다. 그런 흐름을 봐야 하면 사람에게 넘긴다.

1. **배포가 끝났나** — 병합된 배포 PR 의 병합 커밋에서 Vercel 배포가 성공했는지 본다.
   ```bash
   gh api repos/depromeet/19th-team1-client/commits/<병합 커밋>/status \
     -q '.statuses[] | select(.context | test("Vercel")) | .state + " " + .target_url'
   ```
2. **무엇을 볼지** — 배포 PR 의 "포함된 PR" 중 사용자가 겪는 변화가 있는 것. 그리고 늘 보는 것: 첫 화면, 주요 화면 진입.
3. **열어 보기** — 브라우저 도구로 **휴대폰(390) · 데스크톱(1280)** 두 크기. 바뀐 화면이 운영에서 보이나 · 콘솔 에러 · 실패한 네트워크 요청 · `dev` 에서 본 것과 다른 점.
4. **문제가 있으면** — 고치지 않고 보고한다. 되돌릴지(이전 배포로 되돌리기는 Vercel 프로젝트 관리자가 한다), 고쳐서 다시 배포할지는 사람이 정한다.
5. **보고** — 확인한 커밋·주소, 본 화면과 크기, 에러, `dev` 와 다른 점, 보지 못한 흐름과 이유.
