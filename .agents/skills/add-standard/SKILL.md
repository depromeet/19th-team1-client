# 기준 올리기

장부의 규칙은 `docs/code-standards.md` 머리에 있다. 요약: 두 번째 지적 → 번호, 번호 뒤에 또 → 경로별 룰, 그래도 또 → 기계.

1. **이미 있나** — 장부에서 같은 기준을 찾는다(제목·본문 검색, 보류 표 포함).
   - 없으면 2번.
   - 있으면 지금 걸리는 방식을 보고 한 단계 위를 제안한다:
     `글` → 경로별 룰(`.claude/rules/*.md`)에 한 줄 · 룰에 있는데 또 → ESLint 규칙·훅·CI 검사 초안.
     기계로 올리면 지금 코드에서 몇 곳이 걸리는지 세어 함께 보고한다(`pnpm lint` 결과). 룰 문장은 지운다.
2. **한 문장으로** — 지적을 "다음에도 같은 지적을 할" 일반 기준으로 바꾼다. 그때만의 취향이면 올리지 않고 그렇게 보고한다.
3. **항목 쓰기** — 다음 번호(마지막 번호 + 1, 폐기 번호도 건너뛴다)로 맞는 절 끝에 넣는다.
   ```md
   ### C-xx 한 줄 기준 · `초안` · `글`

   - 기준: 무엇을 하고 무엇을 하지 않나
   - 왜: 어기면 무슨 일이 생기나
   - 출처: #PR번호 (첫 지적), #PR번호 (두 번째)
   - 날짜: YYYY-MM-DD
   ```
4. **연결** — 그 영역 경로별 룰에 넣을 만하면 한 줄 초안을 같이 보여 준다. 어떤 파일 종류에 대는 기준인지도 적는다(리뷰어·에이전트가 번호를 고를 때 쓴다).
5. 장부 변경은 문서 PR 로 올린다. 상태는 `초안` 으로 두고, 팀 리뷰에서 `확정` 한다. 확정·폐기는 사람이 바꾼다.
